# Application-owned collaboration and agent-directed work

Status: accepted; updated 9 September 2026.

Conversations belong to the Application and share durable operational state. They are not owned or closed by user-visible launch stages. The agent investigates and revises work toward the user's goal; tools enforce authority and verify effects.

Use conversation-first interaction with shared receipts and stable views. Preserve transcript, draft, origin, evidence and required attention across navigation. The UI does not need a permanent secondary panel or arbitrary generated frontend code.

Application-owned chat persistence and the first real deployment projection now exist. Legacy phase/preparation records still require migration with their evidence and checks preserved. [Roadmap](../../ROADMAP.md) owns completion status; [the integration report](../design/2026-09-09-conversation-first-integration.md) records the current UI mechanism.
