Which stage owns a gap

Being backed up is three facts in order, and every bug this page has had was two of them folded together. So the page is three stages, and each one reports its own result and nobody else’s. That only settles anything if there is a rule for the awkward case: the application keeps something that is not in the newest copy. The gap belongs to the stage whose own record names it, and when no record names anything, no stage is at fault and the page says so.
