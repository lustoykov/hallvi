1. Boundaries and trust

Facts survive; effects are guarded. A preview or command run is a durable row bound to the Pi Run and the exact tree digest; it stays after cancellation as worker evidence and never satisfies a gate. The staged change and behavior checks are effects that only the final transaction saves, guarded against a contract that changed underneath them. Publication is a separate controller-side effect with its own receipt; a lost receipt is reconciled from GitHub before anything is created again.
