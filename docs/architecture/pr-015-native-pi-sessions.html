Server Guy · PR 15 · Native sessions

One conversation, many requests.

Pi now retains each chat’s native messages, tool results and compaction history. Server Guy still records which requests actually succeeded and which Decisions were saved.

Cancellation does not erase your message. It saves a cancelled attempt, commits none of its staged Decisions, and stops both reply generation and compaction. The worker cannot hand off its writer slot until the SDK settles; if it cannot stop, the worker exits.
