Architecture · PR 8 · persistence boundary

One schema, typed queries, the same SQLite database

Drizzle replaces handwritten schema bootstrap and unchecked row mapping. It does not replace SQLite, better-sqlite3, the domain functions, or their transaction boundary.

Changed

  • db-schema.ts declares columns, keys, constraints, and indexes.
  • db.ts uses typed Drizzle builders instead of SQL strings and generic row casts.

Preserved

  • Seven tables, domain function signatures, ordering, JSON values, and atomic Decision replacement.
  • SQLite, better-sqlite3, WAL, foreign keys, and synchronous transactions.

Deferred

No versioned migrations, PostgreSQL, Pi Run, worker, authentication, streaming, or Phase 2 records.
