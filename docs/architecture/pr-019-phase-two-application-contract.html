Server Guy · PR 19 · Phase 2 Application Contract

Inspect at one commit, then write the contract down with its sources.

An explicit Continue completes the Launch Brief and opens Inspect app. Server Guy pins the repository to one commit and records its tree; Pi reads the files it needs through scoped, read-only tools, and every read becomes a saved Observation before the model sees it. The contract Pi proposes is validated field by field against those records, profile rules and the engineer's own words, and saved only with the final answer.

Facts survive cancellation; effects do not. A file read saved during a Run is a receipt of what the repository contained at that commit and stays after cancellation, timeout or failure. The staged contract is an effect that only the final transaction publishes; a stale revision, a changed commit or a rejected field fails the attempt and rolls everything back. Retry reuses the saved reads.
