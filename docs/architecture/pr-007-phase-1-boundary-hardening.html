Architecture · PR 7 · Phase 1

Untrusted data stops at a schema

Browser requests and Pi replies enter through separate Zod schemas. Only fully validated, size-bounded values reach the Phase 1 domain; invalid input stops before any durable write.

Changed boundary

Routes parse unknown data once

Application, Chat, and message bodies use strict schemas. Missing fields, wrong types, unknown fields, malformed JSON, and oversized values return HTTP 400 before a domain function runs.

Model contract

Pi replies fail as one unit

Server Guy no longer silently drops malformed Decisions or truncates their values. Unsupported kinds, invalid replacement IDs, unexpected fields, and size violations reject the turn without writing a partial transcript.

Unchanged

No new product machinery

  • Pi remains the only agent runtime.
  • SQLite remains authoritative.
  • No OAuth, worker, streaming, or Phase 2 behavior is added.
