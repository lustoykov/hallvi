About AI usage & automatic runs

Automatic checks run on every PR and push to main. The browser smoke journeys are the automatic subset of the full browser suite.

On demand means you start the tests yourself, here or in GitHub Actions. The tests still run automatically after you start them. Live evals and LLM advice are local-only; this dashboard asks for confirmation before using your ChatGPT subscription.

Browser tests use simulated Pi, GitHub and login responses, with no AI calls. GitHub-hosted runs still consume Actions minutes.

        How triage works
        Needs attention includes unjudged answers, failures and uncertain judgments. LLM-cleared answers passed the current judge policy and recorded code checks; they are not human-approved. Older advice stays visible but needs rejudging. Human verdicts remain separate and never override failed code checks.
        Before relying on clearance, compare the judge with your own labels on a small set including known failures. Then periodically spot-check cleared answers: the judge can be confidently wrong. Spot-checking opens a random cleared answer; it does not save a verdict.
