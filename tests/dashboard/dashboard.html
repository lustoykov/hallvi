AI usage & automatic runs

        
Automatic checks run on every PR and push to main. The browser smoke journeys are the automatic subset of the full browser suite.

        
On demand means you start the tests yourself, here or in GitHub Actions. The tests still run automatically after you start them. Nothing this dashboard starts calls a model or costs anything: the live eval runner and its model judge have been retired, and their saved answers remain readable under Eval archive.

        
Browser tests run the native Pi SDK with synthetic model, GitHub and login responses. No AI calls; GitHub-hosted runs still consume Actions minutes.
